How to use this document

Work through the parts in order — later tests depend on data created by earlier ones. Each test gives the role required, the exact steps, and the exact result to expect. Tick Pass or Fail and write a note for anything that fails.

Allow about 90 minutes for a complete pass. Part 0 must be finished before anything else.

Before you demonstrate this to your adviser

Run the whole walkthrough yourself first and fix anything that fails. A test marked Pass that fails in front of a panel costs more than an honest Fail written down in advance.

T4.3A reading with no token is rejectedTERMINAL
  1. Post a reading without an Authorization header:
curl.exe -i -X POST http://localhost:8000/api/sensors/1/readings ^
  -H "Content-Type: application/json" -H "Accept: application/json" ^

Expected: HTTP 401. No reading is stored and no alert is raised. This is the security fix: without it, anyone could fabricate a flood and trigger real evacuation messages.

T4.4A reading with a valid token is acceptedTERMINAL

curl.exe -i -X POST http://localhost:8000/api/sensors/1/readings ^
  -H "Content-Type: application/json" -H "Accept: application/json" ^
  -H "Authorization: Bearer PASTE_TOKEN_HERE" ^
  -d "{\"water_level\":1.42,\"temperature\":28.4,\"humidity\":81,\"battery_level\":76.5}"
Expected: HTTP 201 with the created reading in the response body.
Pass   Fail   Notes: ______________________________

PowerShell note

In PowerShell, curl is an alias for a different command. Type curl.exe with the extension, and use ^ for line continuation as shown. In Git Bash use curl and \ instead.

Be ready for this question

If an adviser asks what the confidence percentage means, the correct answer is: it is R² × 100 — how closely the recent readings fit a straight line, not the probability that the forecast is correct. A steady rise gives high confidence; an erratic one gives low confidence. Saying this plainly is stronger than overclaiming.

This is the honesty point to highlight

SMS is recorded as simulated, never as sent, and carries no delivery timestamp — so a simulated message can never be mistaken for a delivered one. Real SMS can be enabled by setting SMS_GATEWAY=semaphore with a provider key; no code changes are required.

Known limitations to declare, not hide

If an adviser asks about any of the following, these are the correct answers. Each is a stated design decision, not an oversight.

AreaPosition
SMS deliverySimulated by default and recorded as such. A live Philippine gateway can be enabled by configuration alone.
Push notificationsNot implemented in this version.
Prediction modelOrdinary least-squares linear regression. Confidence is goodness of fit, not forecast probability. LSTM is future work once a multi-season dataset exists.
ActuationFully implemented in software; demonstrated with low-voltage prototype hardware. Does not control municipal infrastructure.
Evacuation routingA direct heading to the nearest available shelter. No road-routing engine is integrated.
Weather dataSimulated unless an OpenWeatherMap key is configured.
Field hardwareSensor nodes are on order. The ingestion path they will use is already live and is proven by T4.2 – T4.6.
